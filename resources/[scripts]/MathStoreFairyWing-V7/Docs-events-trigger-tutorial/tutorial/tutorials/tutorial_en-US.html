Introduction

What is Fairy Wing V7?

MathStore Fairy Wing V7 is an advanced fairy wings resource for FiveM that includes animated wings, a flight system, an interactive radial HUD, and advanced permission callbacks.

Interface

Integrated Radial HUD

Fairy Wing V7 features a complete radial HUD that allows you to control all resource functions visually and intuitively. To open it, use the configured command or the keybind.

Initial Menu — Equipping Wings

When opening the HUD for the first time (with nothing equipped), the initial menu appears with the central option:

  • GET WINGS (center) — Equips the wings
Initial menu: click to equip your wings

When clicking on any option, a panel will appear for you to enter the desired ID (color).

Wing ID (color) selection panel

Full Radial Menu

After equipping wings, the full radial HUD is displayed with 4 buttons to control everything:

Button Function
01 — CLOSE WINGSCloses the wings (ground animation)
02 — OPEN WINGSOpens the wings (ground animation)
03 — GET WINGS / REMOVE WINGSToggle: equips or removes the wings
04 — FLAP WINGSFlaps the wings (ground animation)
Full radial HUD with all 4 buttons
Tip: If the equip wings button is grayed out, it means you don't have permission or don't have the required item. Contact the server administrator.
Keybinds

Keybinds

The resource supports configurable keybinds through GTA V's native key mapping system. The player does not need to memorize commands — everything can be done through the HUD and keybinds.

HUD Keybind

The player can configure the keys in GTA V settings under Settings → Keyboard → FiveM and look for the resource option.

GTA Settings > Keyboard > FiveM. In the example, the Q key was assigned, but the player can choose any button

In the settings you will find the option (MathStoreFairyWing-V7) Open/Close HUD Wings. The resource folder name cannot be changed, so it will always show MathStoreFairyWing-V7 followed by the action description.

Action Default Description
Toggle Wings None Open/close the wings
Flight Disabled Enable/disable flight mode
HUD None Open/close the radial HUD
Recommended: The ideal way to configure the key is to go to Settings > Keyboard > FiveM in GTA and assign the desired key. You can also use the /hud7 command to open the HUD and create a manual bind, but the GTA settings method is more practical.
Tip: To close the HUD at any time, simply press ESC.
System

Automatic Removal

Players who leave the server or crash will have their wings automatically removed. This prevents orphaned objects from remaining in the world without an owner.

Note: There may be interference depending on the base/framework used. However, the expected behavior is automatic removal on disconnect. If any wings become bugged, use /asaslimpar7 or /asaslimpar27 to manually clean them up.
Reference

Commands

All commands can be renamed by the server administrator in the configuration file. Below are the default names.

Important: Commands are intended for debug and administration purposes. Players normally use the HUD, which is more intuitive and simple to use.

Wings

/asas7 [1-30] Equips the wings. Accepts a color number from 1 to 30. E.g.: /asas7 5
/remover7 Removes the equipped wings.
/asastg7 Opens or closes the wings.
/asasvoar7 Enables or disables flight mode.
/asascor7 [num] Changes the wing color without removing them.
/abrir7 Wing opening animation on the ground.
/fechar7 Wing closing animation on the ground.
/bater7 Wing flapping animation on the ground.

Cleanup

/asaslimpar7 Removes ALL wings from the world (global). Administrative use.
/asaslimpar27 Removes orphaned/bugged wings near you (without an owner).

HUD

/hud7 Opens or closes the radial HUD.
Note: All command names can be changed by the administrator in the config.lua. The names above are the defaults.
