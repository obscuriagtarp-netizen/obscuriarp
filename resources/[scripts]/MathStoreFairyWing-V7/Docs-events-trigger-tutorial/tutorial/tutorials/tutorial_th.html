HUD แบบวงกลมในตัว

Fairy Wing V7 มี HUD แบบวงกลมครบครันที่ช่วยให้คุณควบคุมฟังก์ชันทั้งหมดของ resource ได้อย่างเห็นภาพและใช้งานง่าย หากต้องการเปิด ให้ใช้คำสั่งที่ตั้งค่าไว้หรือปุ่มลัด

เมนูเริ่มต้น — การสวมใส่ปีก

เมื่อเปิด HUD ครั้งแรก (โดยยังไม่ได้สวมใส่อะไร) เมนูเริ่มต้นจะปรากฏพร้อมตัวเลือกตรงกลาง:

  • รับปีก (ตรงกลาง) — สวมใส่ปีก
เมนูเริ่มต้น: คลิกเพื่อสวมใส่ปีกของคุณ

เมื่อคลิกตัวเลือกใดก็ตาม จะปรากฏแผงให้คุณพิมพ์ ID (สี) ที่ต้องการ

แผงเลือก ID (สี) ของปีก

เมนูวงกลมแบบเต็ม

หลังจากสวมใส่ปีกแล้ว HUD แบบวงกลมเต็มรูปแบบจะแสดงพร้อมปุ่ม 4 ปุ่มเพื่อควบคุมทุกอย่าง:

ปุ่ม ฟังก์ชัน
01 — ปิดปีกปิดปีก (แอนิเมชันบนพื้น)
02 — เปิดปีกเปิดปีก (แอนิเมชันบนพื้น)
03 — รับปีก / ถอดปีกสลับ: สวมใส่หรือถอดปีก
04 — กระพือปีกกระพือปีก (แอนิเมชันบนพื้น)
HUD แบบวงกลมเต็มรูปแบบพร้อมปุ่มทั้ง 4 ปุ่ม
เคล็ดลับ: หากปุ่มรับปีกเป็นสีเทา หมายความว่าคุณไม่มีสิทธิ์หรือไม่มีไอเท็มที่จำเป็น กรุณาติดต่อผู้ดูแลเซิร์ฟเวอร์

ปุ่มลัดสำหรับ HUD

ผู้เล่นสามารถตั้งค่าปุ่มลัดในการตั้งค่า GTA V ที่ ตั้งค่า → แป้นพิมพ์ → FiveM แล้วมองหาตัวเลือกของ resource

ตั้งค่า GTA > แป้นพิมพ์ > FiveM ในตัวอย่างนี้ปุ่ม Q ถูกกำหนดไว้ แต่ผู้เล่นสามารถเลือกปุ่มอื่นได้

ในการตั้งค่าคุณจะพบตัวเลือก (MathStoreFairyWing-V7) เปิด/ปิด HUD Wings ชื่อโฟลเดอร์ resource ไม่สามารถเปลี่ยนได้ ดังนั้นจะแสดง MathStoreFairyWing-V7 ตามด้วยคำอธิบายของการกระทำเสมอ

การกระทำ ค่าเริ่มต้น คำอธิบาย
สลับปีก ไม่มี เปิด/ปิดปีก
บิน ปิดใช้งาน เปิด/ปิดโหมดบิน
HUD ไม่มี เปิด/ปิด HUD แบบวงกลม
แนะนำ: วิธีที่ดีที่สุดในการตั้งค่าปุ่มลัดคือไปที่ ตั้งค่า > แป้นพิมพ์ > FiveM ใน GTA แล้วกำหนดปุ่มที่ต้องการ คุณยังสามารถใช้คำสั่ง /hud7 เพื่อเปิด HUD และสร้าง bind เอง แต่การตั้งค่าผ่าน GTA จะสะดวกกว่า
เคล็ดลับ: หากต้องการปิด HUD ได้ตลอดเวลา เพียงกด ESC
