MathStore: Fairy Wing V7

O sistema completo de asas de fada para FiveM, com HUD integrada, sistema de voo e callbacks de permissão avançados.

Introdução

O que é o Fairy Wing V7?

O MathStore Fairy Wing V7 é um resource avançado de asas de fada para FiveM que inclui asas animadas, sistema de voo, HUD radial interativa e callbacks de permissão avançados.

🧚

Asas de Fada

30 cores de asas com animações e múltiplos estados configuráveis.

🎮

HUD Radial

Interface interativa para controlar todas as funções sem necessidade de decorar comandos.

⚙️

Callbacks Avançados

Sistema de permissões personalizável. Restrinja por grupo, item, VIP ou qualquer lógica.

Interface

HUD Radial Integrada

O Fairy Wing V7 possui uma HUD radial completa que permite controlar todas as funções do resource de forma visual e intuitiva. Para abrir, utilize o comando configurado ou a tecla de atalho.

Menu Inicial — Equipar Asas

Ao abrir a HUD pela primeira vez (sem nada equipado), o menu inicial surge com a opção central:

  • OBTER ASA (centro) — Equipa as asas
Menu inicial: clique para equipar as suas asas

Ao clicar em qualquer opção, surgirá um painel para introduzir o ID (cor) pretendido.

Painel de seleção do ID (cor) da asa

Menu Radial Completo

Após equipar asas, a HUD radial completa é apresentada com 4 botões para controlar tudo:

Botão Função
01 — FECHAR ASASFecha as asas (animação no chão)
02 — ABRIR ASASAbre as asas (animação no chão)
03 — OBTER ASAS / REMOVER ASASToggle: equipa ou remove as asas
04 — BATER ASASBate as asas (animação no chão)
HUD radial completa com todos os 4 botões
Dica: Se o botão de obter asas estiver cinzento, significa que não possui permissão ou não tem o item necessário. Consulte o administrador do servidor.
Atalhos

Teclas de Atalho

O Fairy Wing V7 permite ao jogador configurar teclas personalizadas para ações rápidas através das definições do GTA V.

Tecla de Atalho para a HUD

O jogador pode configurar as teclas nas definições do GTA V em Configurações → Teclado → FiveM e procurar pela opção do resource.

Configurações do GTA > Teclado > FiveM. No exemplo, a tecla Q foi atribuída, mas o jogador pode escolher qualquer botão

Nas configurações encontrará a opção (MathStoreFairyWing-V7) Abrir/Fechar HUD Wings. O nome da pasta do resource não pode ser alterado, pelo que aparecerá sempre MathStoreFairyWing-V7 seguido da descrição da ação.

Ação Padrão Descrição
Toggle Asas Nenhuma Abrir/fechar as asas
Voo Desativado Ativar/desativar modo de voo
HUD Nenhuma Abrir/fechar a HUD radial
Recomendado: A forma ideal de configurar a tecla é aceder a Configurações > Teclado > FiveM no GTA e atribuir a tecla pretendida. Também é possível utilizar o comando /hud7 para abrir a HUD e criar uma bind manual, mas a configuração através do GTA é mais prática.
Dica: Para fechar a HUD a qualquer momento, basta premir ESC.
Sistema

Remoção Automática

Jogadores que saírem do servidor ou sofrerem crash terão as suas asas removidas automaticamente. Isto evita que objetos órfãos permaneçam no mundo sem proprietário.

Nota: Poderão existir interferências dependendo da base/framework utilizado. Contudo, o comportamento correto é a remoção automática ao desligar. Caso alguma asa fique com problemas, utilize /asaslimpar7 ou /asaslimpar27 para limpar manualmente.
Referência

Comandos

Todos os comandos podem ser renomeados pelo administrador do servidor no ficheiro de configuração. Abaixo encontram-se os nomes predefinidos.

Importante: Os comandos destinam-se a fins de debug e administração. Os jogadores normalmente utilizam a HUD, que é mais intuitiva e simples de utilizar.

Asas

/asas7 [1-30] Equipa as asas. Aceita um número de cor de 1 a 30. Ex: /asas7 5
/remover7 Remove as asas equipadas.
/asastg7 Abre ou fecha as asas.
/asasvoar7 Ativa ou desativa o modo de voo.
/asascor7 [num] Altera a cor das asas sem remover.
/abrir7 Animação de abrir as asas no chão.
/fechar7 Animação de fechar as asas no chão.
/bater7 Animação de bater as asas no chão.

Limpeza

/asaslimpar7 Remove TODAS as asas do mundo (global). Utilização administrativa.
/asaslimpar27 Remove asas órfãs/com problemas perto de si (sem proprietário).

HUD

/hud7 Abre ou fecha a HUD radial.
Nota: Todos os nomes de comando podem ser alterados pelo administrador no config.lua. Os nomes acima são os predefinidos.
