MathStore: Fairy Wing V7

Le système complet d'ailes de fée pour FiveM, avec HUD intégré, système de vol et callbacks de permission avancés.

Introduction

Qu'est-ce que le Fairy Wing V7 ?

Le MathStore Fairy Wing V7 est une resource avancée d'ailes de fée pour FiveM qui inclut des ailes animées, un système de vol, un HUD radial interactif et des callbacks de permission avancés.

🧚

Ailes de Fée

30 couleurs d'ailes avec des animations et plusieurs états configurables.

🎮

HUD Radial

Interface interactive pour contrôler toutes les fonctions sans avoir à mémoriser des commandes.

⚙️

Callbacks Avancés

Système de permissions personnalisable. Restreignez par groupe, objet, VIP ou toute autre logique.

Interface

HUD Radial Intégré

Le Fairy Wing V7 dispose d'un HUD radial complet qui permet de contrôler toutes les fonctions de la resource de manière visuelle et intuitive. Pour l'ouvrir, utilisez la commande configurée ou la touche de raccourci.

Menu Initial — Équiper les Ailes

Lorsque vous ouvrez le HUD pour la première fois (sans rien équipé), le menu initial apparaît avec l'option centrale :

  • PRENDRE AILES (centre) — Équipe les ailes
Menu initial : cliquez pour équiper vos ailes

En cliquant sur n'importe quelle option, un panneau apparaîtra pour que vous saisissiez l'ID (couleur) souhaité.

Panneau de sélection de l'ID (couleur) de l'aile

Menu Radial Complet

Après avoir équipé les ailes, le HUD radial complet s'affiche avec 4 boutons pour tout contrôler :

Bouton Fonction
01 — FERMER LES AILESFerme les ailes (animation au sol)
02 — OUVRIR LES AILESOuvre les ailes (animation au sol)
03 — PRENDRE AILES / RETIRER AILESBascule : équipe ou retire les ailes
04 — BATTRE LES AILESBat les ailes (animation au sol)
HUD radial complet avec les 4 boutons
Astuce : Si le bouton pour prendre les ailes est grisé, cela signifie que vous n'avez pas la permission ou que vous ne possédez pas l'objet requis. Consultez l'administrateur du serveur.
Raccourcis

Raccourcis Clavier

Le Fairy Wing V7 prend en charge les raccourcis clavier natifs de FiveM. Le joueur peut configurer la touche dans les paramètres du jeu pour ouvrir le HUD sans taper de commande.

Touche de Raccourci pour le HUD

Le joueur peut configurer les touches dans les paramètres du GTA V sous Paramètres → Clavier → FiveM et chercher l'option de la resource.

Paramètres du GTA > Clavier > FiveM. Dans l'exemple, la touche Q a été attribuée, mais le joueur peut choisir n'importe quel bouton

Dans les paramètres, vous trouverez l'option (MathStoreFairyWing-V7) Ouvrir/Fermer HUD Wings. Le nom du dossier de la resource ne peut pas être modifié, il apparaîtra donc toujours MathStoreFairyWing-V7 suivi de la description de l'action.

Action Par défaut Description
Basculer Ailes Aucune Ouvrir/fermer les ailes
Vol Désactivé Activer/désactiver le mode de vol
HUD Aucune Ouvrir/fermer le HUD radial
Recommandé : La manière idéale de configurer la touche est d'aller dans Paramètres > Clavier > FiveM dans le GTA et d'attribuer la touche souhaitée. Il est également possible d'utiliser la commande /hud7 pour ouvrir le HUD et de créer un bind manuel, mais la configuration via le GTA est plus pratique.
Astuce : Pour fermer le HUD à tout moment, appuyez simplement sur ÉCHAP.
Système

Suppression Automatique

Les joueurs qui quittent le serveur ou subissent un crash verront leurs ailes supprimées automatiquement. Cela évite que des objets orphelins restent dans le monde sans propriétaire.

Note : Des interférences peuvent survenir selon la base/framework utilisé. Mais le comportement normal est la suppression automatique à la déconnexion. Si des ailes restent buguées, utilisez /asaslimpar7 ou /asaslimpar27 pour les nettoyer manuellement.
Référence

Commandes

Toutes les commandes peuvent être renommées par l'administrateur du serveur dans le fichier de configuration. Ci-dessous figurent les noms par défaut.

Important : Les commandes sont destinées à des fins de debug et d'administration. Les joueurs utilisent normalement le HUD, qui est plus intuitif et simple à utiliser.

Ailes

/asas7 [1-30] Équipe les ailes. Accepte un numéro de couleur de 1 à 30. Ex : /asas7 5
/remover7 Retire les ailes équipées.
/asastg7 Ouvre ou ferme les ailes.
/asasvoar7 Active ou désactive le mode de vol.
/asascor7 [num] Change la couleur des ailes sans les retirer.
/abrir7 Animation d'ouverture des ailes au sol.
/fechar7 Animation de fermeture des ailes au sol.
/bater7 Animation de battement des ailes au sol.

Nettoyage

/asaslimpar7 Supprime TOUTES les ailes du monde (global). Usage administratif.
/asaslimpar27 Supprime les ailes orphelines/buguées à proximité (sans propriétaire).

HUD

/hud7 Ouvre ou ferme le HUD radial.
Note : Tous les noms de commande peuvent être modifiés par l'administrateur dans le config.lua. Les noms ci-dessus sont ceux par défaut.
